Zoom Webinar CSV 変換ツール

名簿や申込リストを、Zoomインポート用CSV（Email, First Name, Last Name）に変換します（ブラウザ内のみで処理）。

1. 元データの入力

Excelやスプレッドシートからコピー＆ペースト、またはCSV/TSVファイルを指定してください。
・タブ区切り（Excelのコピー）とカンマ区切り（CSV）、および「メールアドレス＋スペース＋氏名」の形式に対応しています。
・氏名を1つのセル（フルネーム）にしている場合は、その列を「First Name」に割り当てれば、Zoom上ではフルネームとして表示されます。

2. 列の対応付け

プレビューを確認し、Zoom側の「Email / First Name / Last Name」に対応する列を選択してください。
Zoomのインポート形式は「Email, First Name, Last Name」の3列のみです。
First Name / Last Nameが不要な場合は、どちらか片方だけ指定しても構いません（空欄になります）。

3. Zoom用CSVの生成

Zoomの「CSVからのインポート」で読み込める形式のCSVを生成します。
zoom_registrants.csv をダウンロード
・CSVを保存する際の文字コードはUTF-8です。ZoomのCSVインポートでも推奨されています。
・Zoom側では、ウェビナー／ミーティングともに「Email, First Name, Last Name」の順でCSVを読み込みます。
GitHub公開用のシンプルなスタンドアロンHTMLです（JavaScript / 外部依存なし）。
